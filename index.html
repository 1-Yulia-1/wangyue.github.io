# 项目：数字媒体艺术个人作品集网站 部署目标：Github Pages纯静态SSG站点，仅浏览器前端交互，禁止后端、服务端组件。 技术栈：Astro + Tailwind CSS；使用React交互岛屿实现局部JS交互；优先使用浏览器原生 View Transitions API 做页面之间的柔和转场动画，减少JS负担。 整体视觉调性：低饱和度深色美术馆，克制高级，不要过度花哨特效；适合求职与艺术申请。 ## 页面与交互需求 1.【Home首页】 首页hero简短个人tagline之后，做pinned固定区块；鼠标向下滚动时驱动内容横向平移，实现横向滑动精选画廊；展示6‑8个精选项目封面；点击封面直接跳转对应作品详情页。 移动端下，首页横向画廊自动降级为普通竖向滚动作品列表，取消横向滚动逻辑。 2.【Works作品索引页】 松散、非严格对齐的不规则作品网格，不要整齐行列； 鼠标hover每一张作品缩略图：图片产生微小位移+微弱放大，同时项目标题文字平滑浮现叠加在图上； 滚动页面时，各个网格项目带有滚动触发的渐入进场动画。 3.【全局自定义跟随光标（React岛屿组件）】 ❗仅桌面端启用；移动端完全禁用该组件，直接使用系统原生光标。 效果：一个轻薄空心白色小圆跟随鼠标移动； 当悬浮在可交互元素：图片、链接、按钮上时，圆形光标平滑放大；离开之后恢复原有小圆尺寸。 注意性能：mousemove事件使用requestAnimationFrame，避免高频重渲染造成页面卡顿；不要添加glitch或者扭曲滤镜。 4.【Work详情页】 独立子页面；支持大尺寸作品图像展示、图片画廊轮播；优先iframe嵌入外部Vimeo/B站演示视频；预留创作论述文本区域，可以放过程稿、媒介说明、创作年份。 5.【About页面】 个人简介、教育背景、创作方向、软件技能（Processing，TouchDesigner等）。 6.【Contact页面】 邮箱以及社交链接；不要后端表单，仅静态联系信息。 ## 硬性约束 1. 全部输出静态站点源码，适合后续Github Action部署上Github Pages； 2. 图片统一开启懒加载；媒体策略：大视频不要存入仓库，只用iframe外链；少量很小的演示短视频可以放入assets； 3. 响应式优先，所有动效在移动端关闭重型JS交互； 4. 不要生成自动部署脚本，我后续自行配置CI；输出完整可Git管理项目源码。
